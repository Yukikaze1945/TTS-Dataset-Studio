# 核心工作流操作体验设计

## 问题

旧界面把源字幕/导出区间与生成/增强音频片段视为互斥选择。任务完成后，
结果片段会接管选择状态，上下文操作栏因此隐藏识别、生成、音频处理和导出。
用户点击下一句字幕时，旧结果焦点还可能残留，造成“功能突然消失”。

这不是单一按钮缺失，而是选择模型与操作目标不一致。

## 采用方案：双层选择

工作区同时维护两种状态：

1. **源工作片段**：字幕或导出区间。识别、生成、音频处理和导出的目标。
2. **结果焦点**：AI 生成或增强片段。只影响结果试听、移动、裁边、定位和删除。

结果焦点不得清除源工作片段。用户选择新的字幕或源区间时，应清除旧结果焦点，
并立即把完整工作流操作作用到新的源片段。

## 操作规则

- 点击字幕：单选对应源片段并移动播放头；Ctrl+点击追加多选。
- 点击生成/增强片段：只聚焦结果，不替换当前源片段。
- 点击时间线空白：移动播放头并取消结果焦点，不创建新选区，也不清除源片段。
- 生成或处理完成：结果获得视觉焦点，但源片段保持选中。
- 结果没有可用源选择时：自动恢复其 `reference_region_id` 对应的源片段。
- “定位源片段”：选中结果的参考区间、移动播放头并退出结果焦点。
- `X`：有结果焦点时删除结果；否则删除源片段。
- `Enter`：优先试听源片段；没有源片段时试听结果范围。
- `E`、识别、生成和音频处理始终作用于源片段。

## 上下文操作栏

- 不再用结果选择替换整套操作。
- 同时显示源片段摘要与结果焦点说明。
- 识别、生成、音频处理和导出保持稳定位置。
- 没有源片段时保留入口但禁用，并通过提示说明如何建立源片段。
- 结果焦点出现时增加“定位源片段”，删除按钮明确删除结果。
- 任务完成提示明确告知源片段仍保持选中，可直接继续下一段。

## 轨道监听

- 原声、AI 和增强轨的 `M`/`S` 保持固定位置。
- 状态不仅依赖颜色，同时使用高亮形状和状态栏文字反馈。
- 提示明确说明 `M = 静音`、`S = 独奏`、Solo 优先。
- 试听和导出继续使用同一套可听轨道规则，避免预览与成品不一致。

## 验收流程

1. 选择源字幕并生成或增强。
2. 结果加入音轨并获得焦点，操作栏仍显示识别、生成、处理和导出。
3. 点击下一句字幕，旧结果焦点消失，新源片段立即成为操作目标。
4. 点击旧结果可移动、裁边或删除；点击“定位源片段”可回到参考区间。
5. 点击空白只移动播放头，不产生残留选区或丢失源工作片段。
6. Mute/Solo 的状态在时间线、状态栏、试听和导出中一致。
