# TTS Dataset Studio — Studio Fluent Minimal 重构

## 目标

让第一次打开软件的用户不需要阅读说明即可完成：

`导入素材 → 选择字幕或声音区间 → 试听 → 导出`

现有字幕编辑、MOSS ASR、IndexTTS2、AI 音轨、工程保存和高级导出能力全部保留，但不再同时占据主界面的视觉注意力。

## 方案比较

### A. 仅替换配色

风险最低，但无法解决顶栏、素材栏、属性面板与时间线权重相同的问题，不采用。

### B. 渐进式重构现有 PySide6 组件（采用）

保留领域模型、播放与任务控制器，替换应用外壳、导航、主题和组件组织。每个阶段都能独立测试与回退，适合当前已有完整工作流的代码库。

### C. 全量重写界面

自由度最高，但会同时触碰播放器、拖拽、时间线命中测试和 AI 状态，回归风险过大，暂不采用。

## 视觉方向

风格名称：**Studio Fluent Minimal**

- Windows 11 原生感与专业音频工作站的组合。
- 深色模式使用深蓝灰而不是纯黑；浅色模式同步设计，不做简单反相。
- 单一蓝紫品牌色负责主要动作和焦点，薄荷色只用于波形与音频状态。
- 使用 4/8 px 间距系统，圆角限定为 6/10/14 px 三档。
- 控件不依靠颜色单独表达状态；选择、禁用、错误均同时使用文字或形状。
- 动效仅用于抽屉、任务和状态过渡，目标时长 120–180 ms。

## 信息架构

### 空状态

- 只展示产品标识、价值说明、导入按钮和三步提示。
- 顶栏保留项目菜单、设置和帮助，但降低视觉权重。

### 工作区

1. 顶栏：项目菜单、工程名、时间码、导入、撤销/重做、设置。
2. 左侧：使用“素材 / 字幕”标签分离两类对象，避免单栏堆叠。
3. 中央上方：视频或波形预览、播放控制。
4. 中央下方：源声音、AI 音轨和字幕时间线。
5. 底部上下文栏：只显示当前选择能执行的操作。
6. 右侧属性抽屉：按需打开，不常驻。
7. 底部任务栏：统一承载导出、识别、生成和缓存状态。

## 行为约束

- 1024 px 以下自动收起素材栏，属性抽屉打开时优先让出素材栏。
- 所有主要按钮至少 36 px 高，图标型按钮至少 32 × 32 px。
- 键盘焦点必须可见，Tab 顺序与视觉顺序一致。
- 后台操作超过 300 ms 必须显示进度或忙碌状态。
- 时间线拖拽与播放头更新保持在主线程每帧预算内，不添加装饰性连续动画。

## 分阶段验收

1. 设计系统、欢迎页、顶栏与左右布局完成，现有 GUI 测试通过。
2. 素材/字幕侧栏、预览控制与上下文栏完成，1024×720 无挤压。
3. 时间线、属性抽屉和任务反馈统一，深浅主题截图通过检查。
4. 全量测试、安装版启动检查与真实媒体工作流通过后合入 `release/github`。
